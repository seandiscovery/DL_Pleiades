# DL Pleiades: Linking Deep Neural Nets to Improve b-Tagging at the ATLAS Experiment

## Introduction
This repository contains code for the DL Pleiades framework, designed to integrate a track-level RNN and jet-level FNN for b-tagging at the ATLAS experiment. It is a hybrid of DL1 code (ATLAS flavor tagging group), RNN code written by Nicole Hartman (SLAC-ATLAS), and integration code written by Sean Mullane (Stanford University Department of Physics).

The ultimate goal of this project is to construct a unified framework for a jet-level deep FNN (using the same input variables as DL1), a track-level RNN, and an end-to-end (ETE) network that combines the FNN and RNN. Please see the repository's Wiki for an introduction and instructions for use.
